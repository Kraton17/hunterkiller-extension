# 🚀 QUICK INSTALLATION GUIDE

## Install in 2 Minutes!

### For Chrome/Edge/Brave

1. **Download** the extension folder to your computer

2. **Open** your browser and go to:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`

3. **Enable** "Developer mode"
   - Look for toggle in top-right corner
   - Switch it ON

4. **Click** "Load unpacked" button

5. **Select** the `hunterkiller-extension` folder

6. **Done!** 🎉 
   - Extension icon appears in toolbar
   - Click icon to open popup
   - Start discovering emails!

---

### For Firefox

1. **Download** the extension folder

2. **Open** Firefox and go to:
   ```
   about:debugging#/runtime/this-firefox
   ```

3. **Click** "Load Temporary Add-on..."

4. **Navigate** to the extension folder

5. **Select** the `manifest.json` file

6. **Done!** 🎉
   - Extension active (temporary)
   - For permanent: needs signing

## ⚠️ IMPORTANT: Add Icons First!

Before installing, add icon files to the `icons/` folder:

**Option 1: Use Emoji (Quick)**
1. Go to: https://emoji-to-png.com/
2. Enter: 🎯
3. Download as PNG (128x128, 48x48, 16x16)
4. Rename to: `icon128.png`, `icon48.png`, `icon16.png`
5. Place in `icons/` folder

**Option 2: Custom Icons**
- Create your own 16x16, 48x48, 128x128 PNG files
- Name them: `icon16.png`, `icon48.png`, `icon128.png`
- Place in `icons/` folder

**Option 3: Use Placeholder**
- Google "target icon png"
- Download any target/crosshair icon
- Resize to required sizes
- Place in `icons/` folder

## Troubleshooting

### Extension Won't Load?
- ✓ Check developer mode is enabled
- ✓ Make sure manifest.json exists
- ✓ Add icon files to icons/ folder
- ✓ Reload the extension
- ✓ Check browser console for errors

### No Icon Showing?
- ✓ Add icon files (see above)
- ✓ Reload extension
- ✓ Right-click toolbar → pin extension

### Not Finding Emails?
- ✓ Check domain is correct
- ✓ Increase depth and pages
- ✓ Enable all techniques
- ✓ Try a known domain first (example.com)
